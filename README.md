# Sistema-de-An-lise-Financeira-Inteligente

1. Instale o Python

2. Instale as bibliotecas necessárias
 cole no terminal do VSCode ( pip install streamlit pandas numpy matplotlib )

3. Vá até a pasta onde está o projeto
 ( No terminal, navegue até o local onde você salvou o arquivo app.py. )
EX: cd "C:\Users\SEU_NOME\Área de Trabalho\SISTEMA_ANALISE_DADOS"

4. Execute o sistema com Streamlit 
  cole no terminal ( streamlit run app.py )

5. Envie um arquivo CSV para análise
Quando o sistema abrir escolha um arquivo com:
(preços de ativos, dados financeiros, valores numéricos)

Sistema em Python que automatiza análises financeiras. Calcula retorno, volatilidade e Value at Risk (VaR), além de simular cenários com Monte Carlo. Interface interativa feita com Streamlit e uso de Pandas, NumPy e Matplotlib.
